# Anime — опенинг/эпизод с глиняным маскотом в аниме-подаче (эталон `Desktop/MOTION/claude-anime`, 9:16, 23,7 с)

Движок: `template/src/anime/` — `AnimeVideo.tsx` (раскадровка, камера, герой, враг, луч, оверлеи, звук) и
`AnimeFx.tsx` (2D-слои). Маскот — `cozy3d/Clay.tsx` с `toon: true`.

## Что делает картинку «аниме» (канон, который мы реализовали)
| Приём | Как у нас |
|---|---|
| Cel-shading: 2–3 тона без градиента | `MeshToonMaterial` + `TOON_RAMP` (DataTexture 3×1, Nearest) — `Clay.tsx` |
| Чёрный контур | inverted hull: та же геометрия, `INK` (BackSide, чёрный), `scale 1.045–1.14` |
| Анимация «на двойках» | **только персонаж и враг** считаются от `fa = f − f % 2`; камера, небо, лепестки — от `f` (двойки на камере = подёргивание всего кадра) |
| Жёсткие склейки вместо плавной камеры | массив `SHOTS` (from, pos, look, fov, roll, push) — камера прыгает между планами; внутри плана только лёгкий push |
| Голландский угол, низкий ракурс на силу | `roll` в шоте, низкая камера при power-up и финальной атаке |
| Небо в духе Синкая | `Sky`: градиент зенит→горизонт, кучевые облака из кругов с тёплым низом, солнечный ореол, птицы; `t` день→закат, `pan` сдвиг облаков на склейке |
| Сакура | `Petals` — лепестки с поворотом и «переворотом» (scaleY = |cos|) |
| 集中線 (focus lines) и спид-лайны | `FocusLines` (перетасовка раз в 2 кадра), `SpeedLines` на рывок |
| Кадр удара (impact frame) | `impactFilter`: grayscale + чередующийся invert + contrast(6) на 3 кадра; тряска камеры — затухающие синусы ~12 кадров |
| Ономатопея | `Sfx` — «БАМ!», «ВЖУХ» Russo с обводкой 14 px (`-webkit-text-stroke` + `paint-order`) |
| Карточки способностей | `SkillCard` — влетает справа, наклон, неоновая рамка цвета силы |
| Блики в глазах | `shine` 0..1 в `ClayState` — блик + звёздочка в лице |
| Хатимаки | `band` = фаза ветра: красная повязка с двумя хвостами |
| Титр-карточка | вертикальный `writing-mode: vertical-rl` «КЛОД» + красная плашка «ЭПИЗОД 1»; финал «СНЯТО!» + NEXT EPISODE ▶ |
| Враг | шипастый икосаэдр (смещённые вершины), красные треугольные глаза, глитч-полоски, исчезает на ударе |

Структура ролика (≈24 с): титр → герой получает задание → power-up (крупный план глаз, 3 карточки сил с ударами) →
появление бага (двухплановый → крупный) → рывок + удар + искры → поза героя → финальная атака-луч, небо в закат →
«СНЯТО!» + CTA. Музыка `epic`, SFX: impact на каждой силе и ударе, glitch на баге, riser перед лучом.

## Грабли
- **9:16 и fov**: вертикальный fov 36° даёт по горизонтали ≈ 20°. Средний план маскота (1,1 м) — камера в ~6–7 м,
  двухплановый (герой + враг 2,6 м) — ~11 м. Иначе «оранжевая стена» на весь кадр.
- Фон-небо — DOM-слой под прозрачным `ThreeCanvas` (`gl.alpha: true`), так облака чёткие и дешёвые.
- `toneMapping: NoToneMapping` — toon-цвета должны быть «плоскими», без ACES.
- Луч рендера ставить **за** героем (z −1,4), иначе аддитивный цилиндр засвечивает лицо.
- «баг» TTS читает как «бак» — это нормальное оглушение, не править.
