# «Снято на телефон» — псевдо-реальная съёмка экрана (эталон `Desktop/MOTION/claude-screen`, 9:16, 23,5 с)

Референс r6 (`Desktop/MOTION/refs-x2/r6.jpg`, `r6detail.jpg`): тёмная комната, ноутбук с терминалом Claude Code крупно,
серые плашки поверх данных, кремовая карточка результата с большой красной цифрой и оранжевой кнопкой, телефон на столе
с экраном блокировки (23:51, обои-луна) и уведомлением; камера с руки, сильная ГРИП.

Движок: `template/src/screen/` — `ScreenVideo.tsx` (стол, ноутбук, телефон, камера, ГРИП, объектив, звук) и
`Terminal.ts` (`drawTerminal` — сессия Claude Code как функция кадра; `drawCard` — карточка результата).

## Как сделана «реальность»
| Признак телефонной съёмки | У нас |
|---|---|
| Ручная камера | `camAt`: ключи-планы + дыхание (синусы 37/17 кадров) + микротремор `smoothNoise` (периоды 9 и 4 кадра) + лёгкий roll. Ступенчатый rand раз в 2 кадра дёргал картинку — не возвращать |
| ГРИП / фокус | DOM-слой `backdrop-filter: blur(7px)` с маской-градиентом: резкая полоса `focus` (доля высоты кадра), всё выше/ниже размыто; фокус переводится вместе с камерой |
| Смаз при переводе | на быстрых переходах `blur(speed × 5px)` на весь 3D-слой |
| Автоэкспозиция | `brightness` вспыхивает, когда камера переходит со стола на яркий экран, и проседает в движении |
| Объектив и сенсор | виньетка, лёгкая хроматика по краям (inset box-shadow красный/синий), шум `feTurbulence` в overlay |
| Свет от экрана | голубой point-light перед экраном + `Glow`; тёплый лампа-свет сбоку с тенью |
| Экран | `meshBasicMaterial` с canvas-терминалом (не тонмапится → светится), клавиатура — canvas с раскладкой |
| Телефон | экран блокировки canvas: дата, время, обои; уведомление съезжает сверху |

## Терминал (честные данные)
`SESSION` = набираемый промпт (`typed`: от слова до слова озвучки) + строки `lines` с `at` от слов (`W(...)`):
`tool` (● Bash(...)), вывод (⎿ …), `redact` (серая плашка вместо данных, как в референсе), цвета — зелёный PASS,
жёлтый предупреждение. Все цифры — из настоящего прогона (здесь claude-anime: 711 кадров, 23,7 с, −14,5 LUFS, −1,8 dBTP).
Окно прокручивается само (`maxRows`). Внизу «✻ Работаю…» пока идут новые строки.

## Грабли
- 9:16 видит только ~1,7 м ширины на 3 м — целиться в левую половину экрана (шапка и маркеры ●), к карточке — панорама вправо.
- Телефон снимать сверху (камера y ≈ 2,5), иначе он режется и уходит в расфокус.
- Музыка `lofi`, тихо (0,09 под голосом): это «ночная» подача, SFX — мягкие тики набора, ding уведомления.
